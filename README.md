# 🎯 Emoji Tracker (动画表情目标跟踪) - 纯传统算法实现

基于纯数学运算与传统计算机视觉技术的视频目标稳定跟踪项目。本项目**未使用**任何深度学习框架或现成的 AI 目标检测算法（如 YOLO、`cv2.matchTemplate` 等），完全依靠底层手写的**归一化互相关（NCC）**算法实现。

## ✨ 核心亮点 & 算法优化

为了解决高分辨率视频下纯 Python 双层 `for` 循环带来的灾难性性能瓶颈，本项目在底层算法实现上进行了深度优化：

* **⚡ FFT 频域加速 (Fast Fourier Transform)**：在 `scipy.signal.fftconvolve` 的支持下，将空间域极其耗时的滑窗互相关运算转换至频域进行点乘，时间复杂度从 $O(N \cdot M)$ 骤降至 $O(N \log N)$，实现单帧毫秒级响应。
* **📐 积分图极速方差计算 (Integral Image/Cumsum)**：抛弃传统的局部窗口均值与方差遍历，利用 NumPy 的 `cumsum` 计算二维前缀和，实现在常数 $O(1)$ 时间内获取任意滑动窗口的像素和与平方和。
* **🔍 金字塔分层搜索 (Coarse-to-Fine)**：针对首帧全局搜索，采用图像缩放粗匹配结合局部原图精细定位的策略，大幅缩减首帧盲搜时间。
* **🎯 动态 ROI 预测追踪**：基于目标运动连续性，利用上一帧的目标位置动态裁剪当前帧的兴趣区域（Region of Interest）。在目标形变导致置信度暴跌时（$< 0.12$），具备自适应全局重定位的防抖防丢机制。
* **🎭 多尺度/多姿态模板轮询**：支持构建多视角模板库（正面、侧身、特殊动作），从容应对目标在视频中发生的剧烈形变。

## 📁 目录结构

项目目录结构如下：

```text
task01_emoji_tracker/
│
├── data/                      # 输入数据源
│   ├── 动画表情视频.mp4        # 待处理的原视频
│   ├── small_template_1.png   # 纯净目标模板 (正面)
│   ├── small_template_2.png   # 纯净目标模板 (侧面)
│   └── small_template_3.png   # 纯净目标模板 (其他动作)
│
├── output/                    # 输出结果
│   └── result_tracked.mp4     # 生成的带有轨迹和追踪框的视频
│
├── correlation.py             # 核心算法库：包含手工推导的快速 NCC 算法与分层搜索
├── evaluation.py              # 用于评估结果视频效果            
└── main.py                    # 主控逻辑：视频 I/O、ROI 裁剪、防丢机制与轨迹绘制
